GOLD SCALPER AI

ملفات الموقع:
- index.html: الصفحة الرئيسية
- manifest.webmanifest: إعداد التثبيت على الهاتف
- sw.js: تخزين الصفحة مؤقتاً

النشر على GitHub Pages:
1) ارفع الملفات الثلاثة إلى جذر المستودع (root) واستبدل الملفات القديمة عند السؤال.
2) Settings > Pages > Deploy from a branch > main > /(root) ثم Save.
3) انتظر اكتمال النشر ثم افتح رابط GitHub Pages.

ملاحظات مهمة:
- مصدر السعر الحالي عام وتقريبي (XAUS)، وليس اتصالاً مباشراً بوسيط MT5.
- التحديث كل 15 ثانية، لكن سرعة المصدر وتوفره غير مضمونين.
- إشارات EMA/RSI مبسطة وليست احتمالات نجاح. لا يوجد ضمان 90%.
- التطبيق لا يرسل أوامر تداول ولا يعرف مواصفات عقد وسيطك. جرّبه تجريبياً فقط.
